# DON'T LOOK BEHIND

A small horror game where the goal is simple: survive without getting caught.

## About the Game

DON'T LOOK BEHIND is a 2D horror survival game. You find yourself in a dark environment with limited visibility, and something is out there with you.

Your flashlight is your main way of seeing what's around you. Explore carefully, keep moving, and try to survive until the end.

The game is designed to create tension through darkness, limited visibility, and the fear of not knowing what's following you.

## Controls

| Key | Action |
|---|---|
| W | Move up |
| A | Move left |
| S | Move down |
| D | Move right |
| Mouse | Aim flashlight |
| E | Interact |
| ESC | Pause / Exit |

## Objective

Survive the game, avoid the creature, and make it to the end.

And whatever you do, don't look behind you.

## How to Play

1. Download and extract the game files.
2. Run `DON'T LOOK BEHIND.exe`.
3. Use WASD to move around.
4. Use your mouse to control the flashlight.
5. Stay alert. You're not alone.

## Built With

- Python
- Pygame
